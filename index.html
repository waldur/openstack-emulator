OpenStack Emulator Helm chart

A Helm chart repository. Latest release: 0.6.0.

Install

helm repo add openstack-emulator https://waldur.github.io/openstack-emulator/
helm repo update

helm install openstack-emulator openstack-emulator/openstack-emulator \
  --namespace openstack-emulator --create-namespace --wait

Pin a version with --version 0.6.0. The chart version equals the emulator release tag, and the image it deploys carries the same tag.
